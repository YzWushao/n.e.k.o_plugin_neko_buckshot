# N.E.K.O × Buckshot Roulette 陪玩插件

适配本机 Steam N.E.K.O **0.9.1 / Windows**，控制已安装的原版《Buckshot Roulette》。不改游戏文件，不读取游戏内存，不需要安装游戏 Mod。

源码：[YzWushao/n.e.k.o_plugin_neko_buckshot](https://github.com/YzWushao/n.e.k.o_plugin_neko_buckshot) · [下载 Release](https://github.com/YzWushao/n.e.k.o_plugin_neko_buckshot/releases) · [发布流程](PUBLISHING.md)

当前为首个预览版本。已验证逻辑、界面、权限控制和真实游戏截图；尚未完成完整单机/真实多人对局验证。

运行环境要求 **Windows 桌面版 N.E.K.O 0.9.1 或兼容版本，且宿主包含 Pillow**。本机 Steam 0.9.1 已确认自带该图像库；插件复用宿主 Pillow，不附带与操作系统绑定的第三方二进制文件。不支持 Linux/macOS 游戏控制。独立运行开发测试时可安装 `pyproject.toml` 的 `dev` 可选依赖。

## 单机 / 联机

面板仅有 **单机 / 联机** 两种模式，当前版本只考虑普通玩法。

- **普通单机**：香烟、啤酒、放大镜、手锯、手铐，共 5 种。考虑验弹、手铐控回合、手锯增伤、回血与退弹的组合。
- **普通联机**：香烟、啤酒、放大镜、手锯、肾上腺素、一次性手机、逆转器、干扰器、遥控器，共 9 种。考虑 2–4 人的座位、生命、库存、回合顺序和目标；只操作主人的座位。
- 切换模式会关闭接管并清除上一局弹药记录。需要重新观察当前局面，再手动开启接管。

每次策略比较只使用画面上实际持有的道具。未看清玩家身份、当前回合或目标时先确认，不盲目操作。这个版本不提供“双倍或放弃”选项，不使用过期药。

## 是否接管赌局

- **关闭（默认）**：持续观察前台游戏画面，猫娘分析实弹/空包弹概率、道具与下一步建议。后台禁止鼠标和键盘操作。
- **开启**：猫娘看画面后自主选择一步点击或按键，再观察实际结果。可随时关闭开关，立即回到分析模式。
- **暂停 / F8**：停止观察并关闭接管。重载插件、重启 N.E.K.O 后接管始终关闭。开关不永久保存。

接管开关只能在插件面板手动开启；猫娘不能自行获得操作权限。

## 安装与使用

1. 保持 N.E.K.O 运行。双击本目录 `install.cmd`，或在插件中心导入上一级的 `neko_buckshot.neko-plugin`。使用官方导入流程，不复制文件到 Steam 的内置插件目录。
2. 在插件中心找到 **恶魔轮盘赌陪玩**，点击启动，再打开 **赌局陪玩** 面板。
3. 开启猫娘对话会话，使用支持图片理解及工具调用的模型。插件复用 N.E.K.O 的当前模型，不另配 API Key。
4. 启动原版游戏，推荐窗口或无边框模式。选择 **单机 / 联机**，在面板点击 **开始陪玩**，然后切回游戏。默认只给分析与建议。
5. 需要自动操作时，在面板开启 **是否接管赌局**，再切回游戏。切出游戏时暂停采集与操作，切回后读取新画面继续。

插件优先读取游戏自身的离屏画面，桌宠可以留在游戏上方。若渲染器不支持而回退到可见截图，需要把覆盖窗口移开；鼠标点击的位置始终不能被桌宠或其他窗口挡住。

也可以对猫娘说“开始恶魔轮盘赌陪玩”或“停止恶魔轮盘赌陪玩”。接管开关仍需在面板操作。

默认自动寻找运行中的 `Buckshot Roulette.exe`。若需要限定某个安装位置，可在插件配置页把 `buckshot.game_exe` 设为游戏程序的完整路径，然后重载插件。

## 概率与记录

面板显示下一发实弹和空包弹概率，以及猫娘最近的分析与建议。猫娘通过画面记录新装弹、开枪、啤酒退弹、放大镜验弹和逆转器事件；只有看到结果才记账。

没有验明当前弹时，概率基于剩余弹药分布。例：3 实弹、2 空包弹，下一发实弹概率 60%；已确认打出一发实弹后变为 50%。若一次消耗没看清类型，保留各种可能的后验分布，而不是猜一发类型。验明当前弹后概率为 0% 或 100%；逆转器会同步改变当前弹和剩余弹数的分布。

看漏装弹或动画时，精确概率可能未知或记录不准。可在面板输入已确认数量、记录消耗/验弹/逆转，或清空未知记录。电话透露的“第 N 发”可作为后续弹序输入策略工具，不会误记为“当前弹”；每次发射或退弹后必须更新序号。概率是已记录信息的条件概率，**不是整局胜率**。

策略工具比较当前一轮弹药内的攻击目标、验弹、回血、增伤和控制回合组合，默认搜索预算为 150 毫秒 / 8000 节点。未搜索到终局时按血量、道具和回合控制进行近似评价；不预测下一次发道具或重新装弹。联机采用其他玩家可能针对你的保守假设，搜索中将验弹信息视为共享信息；真实玩家的私有信息与意图可能不同。因此它帮助比较策略，不保证完整博弈最优或通关。

## 运行限制

- 默认每 1.5 秒采样画面，每 6 秒触发一次分析；实际响应受模型、网络和 N.E.K.O 会话调度影响，无法保证捕捉每段短动画。观察和推理会消耗当前模型额度。
- 截图仅取校验过的游戏程序前台客户区；会通过 N.E.K.O 当前模型连接发送给你配置的模型服务。插件不写入截图文件、不读取其他应用内容。
- 仅允许游戏内单步点击及少量按键；旧画面、过期授权、明显变化的场景和非前台窗口会拒绝操作。F8 为轮询停止键，通常在约 0.1 秒内响应；截图或发送正在执行时可能稍有延迟。
- 纯视觉陪玩依赖模型能力，可能看错道具或点击位置，不保证通关。与其他电脑控制插件同时启用时，请避免让其他插件接管同一个游戏。
- 到结算画面先由玩家决定是否继续；本插件不自动启动游戏、不购买内容。

## 开发与验证

源码包括原生 SDK 插件入口、Windows 窗口驱动、概率账本、观察/操作服务和 TSX 控制面板。

独立逻辑测试（Python 3.11，安装 Pillow）：

```powershell
python -m unittest discover -s tests -v
```

在 N.E.K.O 源码环境中运行官方 `neko-plugin check <此目录绝对路径>` 与 `neko-plugin build <此目录绝对路径> -o neko_buckshot.neko-plugin`。

本插件使用 N.E.K.O 的 [插件 SDK](https://project-neko.online/plugins/sdk-reference)、[LLM 工具](https://project-neko.online/plugins/tool-calling)及 [Hosted UI](https://project-neko.online/plugins/hosted-ui)，采用官方包格式和安装 API。道具与联机顺序规则参考[开发者更新记录](https://mikeklubnika.com/logs/log_4)和[官方 Steam 公告](https://store.steampowered.com/news/app/2835570)。
